# Sample Company Handbook

This example document is safe demo content for testing the Local RAG Knowledge Platform.

## Remote Work Policy

Employees may work remotely when their manager approves the arrangement. Remote employees are expected to maintain secure access practices, communicate clearly, and document project updates.

## Security Guidelines

Confidential documents should not be uploaded to external services without approval. Internal knowledge tools should preserve source references so users can verify answers against original documents.

## Engineering Practices

Teams should use code review, automated tests, clear logging, configuration management, and reproducible local development environments.
